# Anti-Slop Design Doctrine

## 1. The Core Diagnosis of "AI Slop"
AI-generated web design defaults to:
- **Floating glowing gradient blobs** (`background: radial-gradient(...) blur(80px)`) with no physical or functional anchor.
- **Uniform soft rounded glassmorphism** (`rgba(255,255,255,0.05)`, `backdrop-blur`) applied indiscriminately to every card.
- **Centered, generic corporate copy** ("Unleash the Power of Quantum with Next-Gen Algorithms").
- **Meaningless floating geometric shapes** (random 3D wireframe spheres floating in empty space).
- **Uniform dark gray background** (`#0f0f15` or `#0b0b14`) with purple/cyan glow borders on everything.

## 2. Hard Anti-Slop Rules
1. **Zero Unanchored Glowing Blobs:** No decorative blurry ambient gradient meshes. Color must belong to a physical substrate, border rule, technical gate, paper surface, or ink fill.
2. **Strict Grid & Concrete Rules:** Mandate visible, structured layout architecture. (e.g. 12-column Swiss grid, physical modular table boundaries, IBM technical document specs, or hard 1px mechanical hairlines).
3. **Typography With Teeth & Exact Names:**
   - Pair an exact historical/functional display face (e.g. `IBM Plex Mono SemiBold`, `Cinzel / PP Editorial`, `Space Grotesk`, `Cabinet Grotesk`, or `Monument Extended`) with a disciplined text face (`IBM Plex Sans`, `Instrument Sans`, `General Sans`).
   - Hard type scales with radical contrast (e.g. 72px / 24px / 13px), not monotonous 32px everywhere.
4. **Authentic Artifacts Over Metaphor:**
   - Instead of a generic floating glowing sphere: use actual LaTeX Hamiltonian matrices ($H = \sum \sigma_z$), authentic Qiskit OpenQASM 3.0 code blocks, true cryogenic thermal telemetry data, or real pulse microwave frequency diagrams ($5.12\text{ GHz}, \pi\text{-pulse}$).
5. **Tactile Substrates & Tangible Color Schemes:**
   - **Direction A: The Swiss Technical Broadsheet / IBM Lab Archive:** Pure Bone / Off-White (`#F3F1EC`), Deep Carbon Ink (`#121316`), International IBM Blue (`#0F62FE`), Ochre Yellow (`#D28E00`), and raw structured tabular matrices with zero border-radius.
   - **Direction B: The High-Contrast Hardline Terminal / ASCII Ledger:** Pure Matte Black (`#000000`), Bone White (`#EAEAEA`), Hard Line Borders (`#262626`), Electric Amber (`#FF9900`), and monospace layout inspired by early Bloomberg / DEC terminals and Qiskit CLI.
   - **Direction C: Constructivist Quantum Hardware / Deep Navy & Copper:** Deep Cobalt Space (`#080E1A`), Raw Copper/Gold Foil (`#C58F3A`), Superconducting Aluminum Silver (`#9AA4B2`), and stark linear diagrams with asymmetrical editorial layout.
